# FOCUS 1.1
Нативный Android-менеджер внимания: Kotlin, Compose, Room, DataStore. Android 8.0+, target SDK 35. Пакет dev.attention.app. Без сети, аккаунтов, рекламы и аналитики.

## Использование
«+» — название, срок, важность. Прогресс изначально 0%. Цвет края — важность; цвет даты — срочность; нейтральная линия — прогресс. Тап на процент открывает ползунок и пресеты. 100% завершает задачу; снижение возвращает её в активные. Круг или свайп вправо завершает задачу с отменой; свайп влево открывает действия. Удаление требует подтверждения.
Календарь включает месяц и ленту дедлайнов. Иконка карты в задачах открывает Priority Map. История хранит завершённые задачи. Категории создаются в дополнительных полях задачи. Поиск учитывает название, заметку и категорию.

## Уведомления
Утренняя сводка включена на 09:00 местного времени. Для точной доставки разрешите уведомления и «Будильники и напоминания» через настройки FOCUS. Если точное время не разрешено, приложение сообщает об этом и использует неточное расписание Android. Нажатие на уведомление открывает сводку или задачу. После перезагрузки, обновления приложения, смены времени/часового пояса расписание пересчитывается.
Выключенный телефон, принудительная остановка приложения и ограничения производителя могут блокировать уведомления. После принудительной остановки приложение нужно открыть снова. Пропущенные при выключенном телефоне уведомления не отправляются задним числом. На физическом телефоне нужно проверить разрешения и ограничения фоновой работы.

## Данные
Room хранит задачи, DataStore — настройки. Дедлайны сохраняют локальные дату и время при смене часового пояса. Без времени срок — 23:59:59. Настройки позволяют экспортировать и импортировать JSON до 10 МБ. Импорт объединяет задачи по UUID и заменяет настройки, не удаляет прочие задачи. Удаление приложения удаляет локальные данные — сначала экспортируйте копию.

## Формула Фокуса
Просроченные — отдельная первая группа. Для остальных: u=1/(1+max(0,часы до срока)/24); score=важность*(1+1.4*u). Если прогресс 80–99% и срок в пределах суток, бонус 0.6. Важность 10 через неделю выше важности 2 через час. Формула изолирована в FocusLogic.kt.

## Сборка
JDK 17; SDK Platform 35; Build Tools 35.0.0. Укажите свой SDK в local.properties или ANDROID_HOME.
./gradlew assembleDebug testDebugUnitTest
./gradlew assembleRelease

Архив включает ключ личной подписи signing/personal.jks и настройки signing/local.properties. Храните его приватно и сохраните для обновлений поверх установленного APK. Ключ исключён из Git. Отображаемое название можно менять независимо от пакета/БД.

## Структура
FocusLogic.kt — чистая логика сроков/ранжирования.
Data.kt — Room, DataStore, ViewModel, backup.
Notifications.kt — AlarmManager и receivers.
Design.kt — дизайн-система и карточки.
MainActivity.kt — навигация и список.
Editor.kt — формы и обучение.
Views.kt — календарь, карта, сводка, история.
SettingsScreen.kt — настройки/экспорт/импорт.

Новое в 1.1, правила прогресса/аналитики и виджет — UPGRADE-1.1.md. Проверки обновления — QA-1.1.md. QA.md относится к первому билду.

Для обновления установите FOCUS-1.1.apk поверх первого билда, не удаляя приложение. Пакет и ключ подписи не изменены. Виджет добавляется через меню домашнего экрана Android → Виджеты → FOCUS. Его можно растянуть на отдельную страницу.

Новые модули: WorkData.kt (миграция, события, repository), EffortLogic.kt (оценки и прогресс), AnalyticsLogic.kt / AnalyticsScreen.kt (агрегация и UI), FocusWidget.kt (системный виджет), BackupCodec.kt (совместимые копии v1/v2).

## Сборка в GitHub Actions
Workflow `.github/workflows/android-build.yml` собирает release-APK при каждом push и по кнопке «Run workflow». Ключ подписи в репозиторий не входит (репозиторий публичный): он передаётся через секреты репозитория (Settings → Secrets and variables → Actions):

- `FOCUS_KEYSTORE_BASE64` — содержимое `signing/personal.jks` в base64.
- `FOCUS_KEYSTORE_PASSWORD` — `storePassword` из `signing/local.properties`.
- `FOCUS_KEY_PASSWORD` — `keyPassword` (необязательно, если совпадает с паролем хранилища).

Все три значения печатает скрипт из папки с архивом (где лежит `signing/`): Windows `powershell -ExecutionPolicy Bypass -File tools\github-secrets.ps1`, macOS/Linux `sh tools/github-secrets.sh`.

При заданных секретах готовый `FOCUS-1.2.0.apk` публикуется в Releases и как артефакт workflow. Без секретов собирается только неподписанный APK: его нельзя установить поверх FOCUS 1.0/1.1.
