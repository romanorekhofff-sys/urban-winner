- 12 тестов объёма и аналитики: взвешивание, равные веса без оценок, смешанные оценки, предел 99% до последнего шага, известный/неизвестный остаток, временной фильтр, нулевой пустой остаток, суммы, периоды, heatmap, нагрузки, сортировка и размеры виджета.
- 3 прежних интеграционных JVM-теста: persistence, backup, DataStore и переход из уведомления сводки.
- 6 интеграционных тестов расширения: миграция реальной схемы Room v1; создание/редактирование/порядок/удаление подзадач; закрытие/отмена/повторное закрытие и неизменяемые снимки; initial/current estimate; backup v2 без дублей; четыре native layout виджета и переходы; новый timestamp повторного завершения даже из устаревшего состояния редактора.
- 1 сценарий виджета: изменение данных обновляет строку, resize меняет композицию, пересоздание host-view сохраняет действия, checkbox завершает простую задачу, комплексная открывается и не закрывается случайно.
- 2 сценария через реальный Compose UI: onboarding → создание → 100% → история → 75% → возврат → календарь → аналитика → карта; комплексная задача 15+45 минут → 25% → полное завершение → возврат → фильтр на 15 минут → аналитика 45 минут без двойного подсчёта.

Миграция проверяется открытием v1 SQLite-файла с прежними колонками в Room v2 и повторным открытием базы. Сохраняются название, дата, время, важность, процент, заметка, категория, timestamps и отметки уже отправленных напоминаний. Старые завершения переносятся в события из доступных v1-данных, без выдуманной оценки времени; неизвестные исторические оценки остаются неизвестными.

## Визуальная проверка
Снимки получены рисованием реального Android View/Compose UI с native graphics в Robolectric API 28, размер 400×850. Проверены главный экран, карточка с автоматическим прогрессом, календарь, аналитика с реальным тестовым объёмом и Priority Map. Это не дизайнерские макеты. В новых деталях убраны повторяющиеся пресеты времени; карточка сохраняет прежнюю иерархию важности, срочности и прогресса.

## Что не подтверждено физическим устройством
Реальная установка APK поверх установленной версии на телефоне не выполнялась: проверены совместимость пакета/подписи/номера версии и миграция базы. Нет доступа к пользовательскому телефону.
Не проверены настоящая перезагрузка телефона/launcher, размещение и растягивание виджета конкретным launcher, доставка уведомлений в энергосбережении, Android 16 и ощущения haptics. Ветвь responsive RemoteViews Android 12+ собирается и проверяется статически; интерактивные JVM-тесты виджета выполнялись на API 28. Эти проверки не следует выдавать за аппаратные.

## Установка и сохранение данных
Установите FOCUS-1.1.apk поверх первого билда. Не удаляйте прежнее приложение: миграция выполняется при первом открытии обновления. Настройки DataStore и имя базы сохранены. Ключ подписи в архиве нужен для будущих обновлений — храните архив приватно.
Виджет: домашний экран → Виджеты → FOCUS, затем растяните панель. Уведомления требуют прежних разрешений Android. После принудительной остановки приложение необходимо открыть снова.
