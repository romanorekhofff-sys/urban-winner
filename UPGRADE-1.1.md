# FOCUS 1.1 — расширение существующего приложения

Пакет dev.attention.app и ключ signing/personal.jks сохранены; versionCode 2. Room v1 → v2: добавление полей и таблиц, без destructive migration. Старые задачи сохраняют progress, даты и настройки; оценка времени остаётся null.

## Правила
- Один уровень подзадач. При наличии подзадач ручной прогресс отключён.
- Все подзадачи оценены: прогресс взвешен по минутам. Хотя бы одна не оценена: прогресс по числу выполненных. До выполнения последней подзадачи максимум 99%.
- Сумма частично оценённого объёма помечается ≥. Фильтр «Есть время» включает только полностью известный остаток. Завершённые неоценённые подзадачи не мешают оценить известный остаток.
- Родитель комплексной задачи не добавляет минут в аналитику. Источник объёма — завершения подзадач; простая задача учитывает собственную оценку.
- Исторические значения важности, срока и объёма фиксируются. Повторное сохранение не создаёт повторное событие. Возврат в активные аннулирует соответствующее завершение; повторное завершение создаёт новое. Удаление закрытой задачи не стирает уже выполненную работу из истории.
- Первое известное значение оценки сохраняется отдельно от текущего. WorkSession подготовлен в базе, но таймеров и расчёта фактического времени нет.
- Аналитика показывает моменты завершения оценённого объёма, а не фактические часы работы.
- Backup v2 включает задачи, подзадачи, события, оценки, настройки и будущие WorkSession. Поддерживается импорт v1. Восстановление задач по ID заменяет их журнал событий из копии; повторный импорт не дублирует объём.

## Виджет
Нативный Android RemoteViews, четыре responsive-композиции на Android 12+ и выбор по размеру на более ранних версиях. 1 / 3 / 6 / 9 задач. Добавляется через меню виджетов launcher, затем растягивается. Заголовок открывает список; + — создание; Дата — календарь. Круг у комплексной задачи открывает её, чтобы случайно не закрыть все подзадачи.
Обновление после изменений, системное каждые 30 минут, после смены времени/перезагрузки и у ближайшей границы срока/суток. Без поминутного wake-up. В режиме энергосбережения Android может отложить фоновое обновление.
