# FOCUS 1.2 — подключение голоса

Готовый APK работает с прежней локальной базой. Для голосовых команд один раз разверните Worker и укажите его адрес в настройках приложения. Сам Android-проект менять и пересобирать для подключения не нужно.

## 1. Подготовьте компьютер

Установите Node.js LTS с https://nodejs.org и распакуйте архив исходников. Откройте терминал в папке `focus/backend/focus-api` (Windows: в адресной строке папки введите `powershell`).

Выполните по очереди:

```sh
npm install
npx wrangler login
npx wrangler deploy
```

В браузере войдите в ваш аккаунт Cloudflare и разрешите Wrangler доступ. Последняя команда создаст Worker `focus-voice-api`, его endpoint и ограничитель запросов из `wrangler.jsonc`. Если имя занято в вашем аккаунте, измените только поле `name` в этом файле и повторите deploy.

Адрес будет напечатан в терминале: `https://focus-voice-api.ВАШ-ПОДДОМЕН.workers.dev`. Его также можно найти на https://dash.cloudflare.com → Workers & Pages → focus-voice-api → Settings → Domains & Routes. Пока secrets не добавлены, команды возвращают 503.

## 2. Добавьте два секрета в Cloudflare

В том же терминале:

```sh
npx wrangler secret put OPENAI_API_KEY
```

Когда команда попросит значение, вставьте ваш OpenAI API key. Не записывайте его в Android, файлы проекта, git или переписку. Другой способ: Cloudflare → Worker → Settings → Variables and Secrets → Add → тип Secret → имя `OPENAI_API_KEY` → значение → Deploy.

Создайте отдельный случайный токен доступа командой:

```sh
node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"
```

Сохраните выданную строку в менеджере паролей. Это APP_TOKEN, не ключ OpenAI. Затем:

```sh
npx wrangler secret put APP_TOKEN
```

Вставьте сгенерированную строку. Больше секретов не нужно. Не вставляйте OpenAI key вместо APP_TOKEN.

## 3. Проверьте OpenAI

На https://platform.openai.com убедитесь, что API-проект имеет доступ к модели `gpt-4.1-mini-2025-04-14`, оплачен и не исчерпал лимиты. Подписка ChatGPT не оплачивает запросы API. Используйте отдельный проект/ключ для FOCUS и настройте бюджетные уведомления. Бюджетное уведомление не следует считать гарантированным жёстким отключением расходов.

Worker вызывает Responses API со Structured Outputs, `store:false`, temperature 0 и пределом 1800 выходных токенов. Модель зафиксирована на сервере; Android её выбирать не может.

## 4. Подключите телефон

1. Установите **FOCUS-1.2.apk поверх существующего FOCUS**, не удаляя старую версию.
2. Откройте FOCUS → шестерёнка → Голосовой ввод → Изменить подключение (при первом запуске поля уже видны).
3. В HTTPS-адрес Worker вставьте адрес из шага 1, без `/command` (оба варианта поддерживаются).
4. В APP_TOKEN вставьте отдельную строку из шага 2.
5. Язык оставьте `ru-RU`. Нажмите «Сохранить подключение».
6. На главном экране нажмите микрофон рядом с + и разрешите использование микрофона.
7. Скажите: «Добавь завтра позвонить Иванову, важность семь».

Должна появиться новая задача; действие можно отменить snackbar-кнопкой. Если распознавание недоступно, в той же панели можно ввести текст и нажать «Отправить текст». Это позволяет проверить Worker независимо от микрофона.

## 5. Проверка POST /command на компьютере

В Windows PowerShell выполните, подставив только адрес и APP_TOKEN:

```powershell
$focusUrl = 'https://focus-voice-api.ВАШ-ПОДДОМЕН.workers.dev'
$focusToken = Read-Host 'APP_TOKEN'
$focusBody = @{
 text = 'Добавь завтра позвонить Иванову, важность семь'
 localDateTime = [DateTimeOffset]::Now.ToString('yyyy-MM-ddTHH:mm:sszzz')
 timezone = 'Europe/Moscow'
 relevantTasks = @()
 appVersion = '1.2.0'
 requestId = [guid]::NewGuid().ToString()
} | ConvertTo-Json -Depth 10
Invoke-RestMethod -Method Post -Uri "$focusUrl/command" -Headers @{Authorization="Bearer $focusToken"} -ContentType 'application/json; charset=utf-8' -Body ([Text.Encoding]::UTF8.GetBytes($focusBody))
```

Timezone должен соответствовать вашему местному времени: например, `Europe/Berlin` для Германии. Ожидается `status: READY`, `action: CREATE_TASK` и абсолютная дата завтрашнего дня. Открыть URL в браузере недостаточно: endpoint принимает только POST.

Ошибки: 401 — APP_TOKEN не совпал; 429 — повторите через минуту или проверьте API-лимиты OpenAI; 503 — отсутствуют secrets/VOICE_LIMIT или временная недоступность; 502 — ошибка OpenAI либо некорректный ответ; 504 — превышено 20 секунд ожидания модели. Сырые ответы OpenAI и ключ не передаются в приложение.

## 6. Основные команды на телефоне

- «Добавь завтра отправить статью, важность девять, минут на двадцать».
- «По статье готово процентов семьдесят».
- «Закрой задачу отправить статью» — потребуется подтверждение.
- «Перенеси статью на следующий вторник» — проверьте показанную дату и подтвердите.
- «Добавь в статью подзадачу проверить источники на сорок минут».
- «Что у меня сегодня?» / «Что самое срочное?» / «Что я успею за час?».

Если названия похожи, выберите задачу в панели и подтвердите результат. Если срок не указан, дополните текст полным сроком и отправьте заново. Если важность не указана, предлагается 5 с подтверждением. Ручной процент комплексной задачи не меняется, он зависит от подзадач. «Следующий вторник» здесь означает вторник следующей календарной недели; «во вторник» — ближайший вторник, включая сегодня. Без точного времени срок — конец дня.

Поддерживается создание одной задачи сразу с подзадачами. Несколько независимых задач одной репликой (Voice Inbox) намеренно не включены в эту версию.

## 7. Сборка самостоятельно

Установите Android Studio с JDK 17 и Android SDK 35. Откройте папку `focus`, дождитесь Gradle Sync. Для командной строки задайте `JAVA_HOME` на JDK 17 и укажите путь к SDK в локальном `local.properties` (`sdk.dir=...`). Это файл исключительно для пути к SDK, без ключей API.

Windows:

```powershell
.\gradlew.bat :app:assembleRelease
```

macOS/Linux:

```sh
chmod +x gradlew
./gradlew :app:assembleRelease
```

Результат: `app/build/outputs/apk/release/app-release.apk`. Устанавливайте release: он подписан тем же личным ключом, что FOCUS 1.0/1.1. Обычный debug подписан другим ключом и не предназначен для обновления установленного release. Не удаляйте прежнее приложение для обхода ошибки подписи.

Архив исходников содержит личный ключ подписи в `signing`; храните его приватно. OpenAI key в архиве отсутствует.

## Конфиденциальность и ограничения

Задачи, аналитика и настройки остаются локальными. Голос требует сети. Системный распознаватель Android может отправлять аудио своему провайдеру; FOCUS аудио на Worker/OpenAI не отправляет. Worker получает текст, локальную дату, часовой пояс и максимум 12 кандидатов, до 20 названий подзадач каждого. Для очевидного создания и запросов список кандидатов пуст. Заметки и аналитика контекстом не отправляются.

Worker не хранит задачи и не пишет их в логи. `store:false` отключает сохранение Responses для дальнейшего получения, но не отменяет политики обработки/служебного хранения OpenAI: https://developers.openai.com/api/docs/guides/your-data.

APP_TOKEN вводится пользователем, хранится с шифрованием Android Keystore и исключён из экспорта. Он ограничивает доступ в личной версии, но не является неуязвимой защитой на скомпрометированном телефоне. При утечке смените APP_TOKEN в Worker и приложении. Для публичного продукта нужна отдельная авторизация.

Cloudflare rate-limit binding ограничивает до 6 запросов в минуту на личный principal в пределах размещения Cloudflare. Это приблизительная распределённая защита, не глобальный финансовый лимит. Пределы длины запроса/ответа и таймаут ограничивают стоимость одного вызова. Нет автоматических повторов платного запроса.

Проверки локального контракта: `cd backend/focus-api` → `npm test`. Эти тесты используют подставленные ответы OpenAI; они не подтверждают реальную точность распознавания намерений. Для проверки живой модели нужны ваши secrets и deploy.

Официальная документация: https://developers.openai.com/api/docs/guides/structured-outputs ; https://developers.openai.com/api/docs/models/gpt-4.1-mini ; https://developers.cloudflare.com/workers/runtime-apis/bindings/rate-limit/ ; https://developers.cloudflare.com/workers/configuration/secrets/ .
